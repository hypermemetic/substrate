# Activation API Reference

16 activations organized by category. All methods return streaming responses via Plexus RPC subscriptions.

---

## Orchestration

### Orcha (`orcha`) -- Hub Activation
**Version:** 1.0.0 | **Storage:** SQLite | **Parent Context:** Yes (via ClaudeCode)

Orchestrates multi-agent task execution with approval loops, validation, and graph-based workflows. Sub-activation: `pm` (ProcessManager) accessible via `orcha.pm.*`.

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|
| `run_task` | `request: RunTaskRequest` | Main entry point -- creates session, runs task with approval handling, validates, auto-retries |
| `run_task_async` | `request: RunTaskRequest` | Fire-and-forget variant of run_task |
| `create_session` | `request: CreateSessionRequest` | Create orchestration session record |
| `update_session_state` | `session_id: SessionId, ...` | Update session state |
| `get_session` | `request: GetSessionRequest` | Get session details |
| `list_sessions` | -- | List all orchestration sessions |
| `delete_session` | `session_id: SessionId` | Delete a session |
| `extract_validation` | `text: String` | Extract validation artifact from accumulated text |
| `run_validation` | `artifact: ValidationArtifact` | Run a validation test command |
| `increment_retry` | `session_id: SessionId` | Increment retry counter |
| `list_monitor_trees` | -- | List arbor monitoring trees for orcha sessions |
| `check_status` | `request: CheckStatusRequest` | Check status of a running orchestration |
| `spawn_agent` | `request: SpawnAgentRequest` | Spawn a sub-agent within a session |
| `list_agents` | `request: ListAgentsRequest` | List agents for a session |
| `get_agent` | `request: GetAgentRequest` | Get agent details |
| `list_pending_approvals` | `request: ListApprovalsRequest` | List pending approval requests for a graph |
| `approve_request` | `request: ApproveRequest` | Approve a pending request |
| `deny_request` | `request: DenyRequest` | Deny a pending request |
| `subscribe_approvals` | `graph_id: String, timeout_secs?: u64` | Push stream of approval events for human-in-the-loop UIs |
| `run_graph` | `graph_id: String, model?: String, working_directory?: String` | Execute a pre-built lattice graph |
| `run_plan` | `task: String, model?: String, working_directory?: String` | Single-call planning -- Claude generates and executes a child graph |
| `cancel_graph` | `graph_id: String` | Stop a running graph and all agent tasks (BFS through children) |
| `subscribe_graph` | `graph_id: String, after_seq?: u64` | Reconnectable observation stream -- replays from cursor then tails live |
| `watch_graph_tree` | `graph_id: String, after_seq?: u64` | Like subscribe_graph but recursively follows child graphs |
| `create_graph` | `metadata: json` | Create an empty execution graph |
| `add_task_node` | `graph_id: String, task: String` | Add a task node (Claude prompt) |
| `add_synthesize_node` | `graph_id: String, task: String` | Add a synthesize node (task with prior-work context) |
| `add_validate_node` | `graph_id: String, command: String, cwd?: String` | Add a validate node (shell command, exit 0 = pass) |
| `add_gather_node` | `graph_id: String, strategy: GatherStrategy` | Add a gather node (auto-executes when all inbound tokens arrive) |
| `add_subgraph_node` | `graph_id: String, child_graph_id: String` | Add a sub-graph node |
| `add_dependency` | `graph_id: String, dependent_node_id: String, dependency_node_id: String` | Declare execution dependency between nodes |
| `build_tickets` | `tickets: String, metadata: json` | Compile ticket DSL into a lattice graph without executing |
| `run_tickets` | `tickets: String, metadata: json, model?: String, working_directory?: String` | Compile and execute ticket DSL |
| `run_tickets_async` | `tickets: String, metadata: json, model?: String, working_directory?: String` | Fire-and-forget ticket execution |
| `run_tickets_files` | `paths: vec[String], metadata: json, model?: String, working_directory?: String` | Read ticket files from disk, compile, and execute |
| `run_tickets_async_files` | `paths: vec[String], metadata: json, model?: String, working_directory?: String` | Fire-and-forget file-based ticket execution |
| `run_graph_definition` | `metadata: json, model?: String, working_directory?: String, nodes: vec[OrchaNodeDef], edges: vec[OrchaEdgeDef]` | Build and execute a graph from inline definition |

**Sub-activation -- PM (`orcha.pm`):**

| Method | Params | Description |
|--------|--------|-------------|
| `graph_status` | `graph_id: String, recursive?: bool` | Ticket-level status of all nodes in a graph |
| `what_next` | `graph_id: String` | Show what tickets are ready to execute |
| `inspect_ticket` | `graph_id: String, ticket_id: String` | Detailed view of a single ticket |
| `why_blocked` | `graph_id: String, ticket_id: String` | Explain why a ticket is blocked |
| `get_ticket_source` | `graph_id: String` | Get the original ticket DSL source |
| `list_graphs` | -- | List all tracked graphs with status |
| `get_node_log` | `graph_id: String, node_id: String` | Get event log for a node |

**Storage tables:**
- `orcha_sessions`: session_id, model, working_directory, rules, max_retries, retry_count, state_type, state_data, agent_mode, primary_agent_id, tree_id
- `orcha_agents`: agent_id, session_id, claudecode_session_id, subtask, state_type, state_data, is_primary, parent_agent_id
- `orcha_ticket_maps`: graph_id, ticket_id, node_id
- `orcha_ticket_sources`: graph_id, source
- `orcha_node_logs`: id (autoincrement), graph_id, node_id, ticket_id, seq, event_type, event_data

**Depends on:** ClaudeCode, Loopback, Lattice, Arbor

### Lattice (`lattice`)
**Version:** 1.0.0 | **Storage:** SQLite | **Parent Context:** No

DAG execution engine. Nodes fire when all predecessors complete. Petri-net token passing on edges.

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|
| `create` | `metadata?: json` | Create an empty graph |
| `add_node` | `graph_id: String, spec: NodeSpec, node_id?: String` | Add a node with typed spec (task/scatter/gather/subgraph) |
| `add_edge` | `graph_id: String, from_node_id: String, to_node_id: String, condition?: json` | Add dependency edge (optional color filter) |
| `execute` | `graph_id: GraphId, after_seq?: u64` | Execute graph, streaming events (reconnectable via cursor) |
| `node_complete` | `graph_id: GraphId, node_id: String, output?: TokenPayload` | Report node completion with output token |
| `node_failed` | `graph_id: GraphId, node_id: String, error: String` | Report node failure |
| `get_node_inputs` | `graph_id: GraphId, node_id: String` | Get collected input tokens for a node |
| `get` | `graph_id: GraphId` | Get full graph state (nodes, edges, status) |
| `list` | -- | List all graphs |
| `cancel` | `graph_id: GraphId` | Cancel a running graph |
| `create_child_graph` | `parent_id: String, metadata?: json` | Create a child graph linked to parent |
| `get_child_graphs` | `parent_id: String` | List child graphs of a parent |

**Storage tables:**
- `lattice_graphs`: id, metadata, status, created_at
- `lattice_nodes`: id, graph_id, spec, status, output, error, created_at, completed_at
- `lattice_edges`: id, graph_id, from_node_id, to_node_id
- `lattice_events`: seq (autoincrement), graph_id, event, created_at
- `lattice_edge_tokens`: edge_id, graph_id, token, seq

**Depends on:** none (leaf)

### Chaos (`chaos`)
**Version:** 1.0.0 | **Storage:** None (reads Lattice) | **Parent Context:** No

Fault injection and observability for anti-fragility testing.

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|
| `list_running_nodes` | -- | List all Running nodes across all lattice graphs |
| `inject_failure` | `graph_id: String, node_id: String, error?: String` | Force-fail a running node |
| `inject_success` | `graph_id: String, node_id: String, value?: String` | Force-complete a running node with an ok token |
| `list_processes` | `pattern: String` | List processes matching a cmdline pattern (via /proc) |
| `kill_process` | `pid: u32` | SIGKILL a process by PID |
| `graph_snapshot` | `graph_id: String` | Full status snapshot of all nodes in a graph |
| `crash` | -- | Hard-crash the substrate process (SIGKILL self) |

**Depends on:** Lattice (reads LatticeStorage)

## Conversation

### Arbor (`arbor`)
**Version:** 1.0.0 | **Storage:** SQLite | **Parent Context:** Yes

Immutable conversation tree storage. Trees hold nodes; nodes are text or external handles. Reference-counted with scheduled deletion.

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|
| `tree_create` | `metadata?: json, owner_id: String` | Create a new tree with root node |
| `tree_get` | `tree_id: TreeId` | Get full tree with all nodes |
| `tree_get_skeleton` | `tree_id: TreeId` | Get tree structure without node content |
| `tree_list` | -- | List all active trees |
| `tree_update_metadata` | `tree_id: TreeId, metadata: json` | Update tree metadata |
| `tree_claim` | `tree_id: TreeId, owner_id: String, count: i64` | Increment reference count |
| `tree_release` | `tree_id: TreeId, owner_id: String, count: i64` | Decrement reference count (schedules deletion at 0) |
| `tree_list_scheduled` | -- | List trees scheduled for deletion |
| `tree_list_archived` | -- | List archived trees |
| `node_create_text` | `tree_id: TreeId, parent?: NodeId, content: String, metadata?: json` | Create a text node |
| `node_create_external` | `tree_id: TreeId, parent?: NodeId, handle: Handle, metadata?: json` | Create an external handle node |
| `node_get` | `tree_id: TreeId, node_id: NodeId` | Get a single node |
| `node_get_children` | `tree_id: TreeId, node_id: NodeId` | Get children of a node |
| `node_get_parent` | `tree_id: TreeId, node_id: NodeId` | Get parent of a node |
| `node_get_path` | `tree_id: TreeId, node_id: NodeId` | Get path from root to node |
| `context_list_leaves` | `tree_id: TreeId` | List all leaf nodes |
| `context_get_path` | `tree_id: TreeId, node_id: NodeId` | Get conversation context path to node |
| `context_get_handles` | `tree_id: TreeId, node_id: NodeId` | Get external handles along path |
| `tree_render` | `tree_id: TreeId` | Render tree as formatted text |

**Storage tables:**
- `trees`: id, root_node_id, ref_count, state, scheduled_deletion_at, archived_at, created_at, updated_at, metadata
- `tree_refs`: tree_id, owner_id, count, claimed_at
- `nodes`: id, tree_id, parent_id, ref_count, state, scheduled_deletion_at, archived_at, node_type, content, handle_plugin_id, handle_version, handle_method, handle_meta, created_at, metadata
- `node_refs`: node_id, owner_id, count, claimed_at
- `node_children`: parent_id, child_id, position

**Depends on:** none (leaf)

### Cone (`cone`)
**Version:** 1.0.0 | **Storage:** SQLite | **Parent Context:** Yes

LLM conversation sessions backed by Arbor trees. Each cone has a model, system prompt, and a head pointer into its tree.

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|
| `create` | `name: String, model_id: String, system_prompt?: String, metadata?: json` | Create a new cone |
| `get` | `identifier: ConeIdentifier` | Get cone by name or UUID |
| `list` | -- | List all cones |
| `delete` | `identifier: ConeIdentifier` | Delete a cone |
| `chat` | `identifier: ConeIdentifier, prompt: String, ephemeral?: bool` | Stream a chat turn (streaming) |
| `set_head` | `identifier: ConeIdentifier, node_id: NodeId` | Move the conversation head pointer |
| `registry` | -- | List available LLM models |

**Storage tables:**
- `cones`: id, name (unique), model_id, system_prompt, tree_id, canonical_head, metadata, created_at, updated_at
- `messages`: id, cone_id, role, content, model_id, input_tokens, output_tokens, created_at

**Depends on:** Arbor (shared ArborStorage)

### ClaudeCode (`claudecode`)
**Version:** 1.0.0 | **Storage:** SQLite | **Parent Context:** Yes

Manages Claude Code CLI sessions with Arbor-backed conversation history. Supports async polling and session import/export.

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|
| `create` | `name: String, working_dir: String, model: String, system_prompt?: String` | Create a new Claude Code session |
| `get` | `name: String` | Get session by name |
| `list` | -- | List all sessions |
| `delete` | `name: String` | Delete a session |
| `fork` | `name: String, new_name: String` | Fork a session (clone tree, new head) |
| `chat` | `name: String, prompt: String, ephemeral?: bool` | Stream a chat turn (streaming) |
| `chat_async` | `name: String, prompt: String, ephemeral?: bool` | Non-blocking chat, returns stream_id |
| `poll` | `stream_id: String, from_seq?: u64, limit?: u64` | Poll events from an async chat stream |
| `streams` | `session_id?: String` | List active async streams |
| `get_tree` | `name: String` | Get the full arbor tree for a session |
| `render_context` | `name: String, start?: String, end?: String` | Render conversation context between nodes |
| `sessions_list` | `project_path: String` | List Claude Code JSONL sessions on disk |
| `sessions_get` | `project_path: String, session_id: String` | Read a JSONL session from disk |
| `sessions_import` | `project_path: String, session_id: String, owner_id?: String` | Import a JSONL session into Arbor |
| `sessions_export` | `tree_id: String, project_path: String, session_id: String` | Export an Arbor tree to JSONL |
| `sessions_delete` | `project_path: String, session_id: String` | Delete a JSONL session from disk |

**Storage tables:**
- `claudecode_sessions`: id, name (unique), claude_session_id, loopback_session_id, tree_id, canonical_head, working_dir, model, system_prompt, mcp_config, loopback_enabled, metadata, created_at, updated_at
- `claudecode_messages`: id, session_id, role, content, model_id, input_tokens, output_tokens, cost_usd, created_at
- `claudecode_unknown_events`: id, session_id, event_type, data, created_at

**Depends on:** Arbor (shared ArborStorage)

### Loopback (`loopback`)
**Version:** 1.0.0 | **Storage:** SQLite | **Parent Context:** No

Routes tool permission requests from Claude Code back to a parent for human-in-the-loop approval. Implements the `--permission-prompt-tool` protocol.

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|
| `permit` | `tool_name: String, tool_use_id: String, input: json, _connection?: json` | Blocks until parent approves/denies (called by Claude Code CLI) |
| `respond` | `approval_id: ApprovalId, approve: bool, message?: String` | Approve or deny a pending request |
| `pending` | `session_id?: String` | Snapshot of all pending approval requests |
| `wait_for_approval` | `session_id: String, timeout_secs?: u64` | Block until a new approval arrives (default 300s timeout) |
| `configure` | `session_id: String` | Generate MCP configuration JSON for a loopback session |

**Storage tables:**
- `loopback_approvals`: id, session_id, tool_name, tool_use_id, input, status, response_message, created_at, resolved_at

**Depends on:** none

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|

| `register` | `plugin_id: Uuid, method: String, name: String, template: String` | Register or update a template |
| `list` | `plugin_id?: Uuid` | List all templates, optionally filtered by plugin |
| `get` | `plugin_id: Uuid, method: String, name: String` | Get a template by identifier |
| `delete` | `plugin_id: Uuid, method: String, name: String` | Delete a template |

**Storage tables:**
- `templates`: id, plugin_id, method, name, template, created_at, updated_at (unique on plugin_id + method + name)

**Depends on:** none

### Changelog (`changelog`)
**Version:** 1.0.0 | **Storage:** SQLite | **Parent Context:** No

Tracks plexus hash transitions and queued planned changes.

**Methods:**

| Method | Params | Description |
|--------|--------|-------------|
| `add` | `hash: String, summary: String, tags?: vec[String]` | Add a changelog entry for a hash change |
| `list` | -- | List all entries (newest first) |
| `get` | `hash: String` | Get entry for a specific hash |
| `check` | `current_hash: String` | Check if current config is documented |
| `queue_add` | `description: String, tags?: vec[String]` | Queue a planned change |
| `queue_list` | `tag?: String` | List queued changes, optionally by tag |
| `queue_pending` | `tag?: String` | List pending (incomplete) queued changes |
| `queue_get` | `id: String` | Get a specific queued change |
| `queue_complete` | `id: String, hash: String` | Mark a queued change as complete |

**Storage tables:**
- `changelog_entries`: hash (PK), previous_hash, created_at, summary, details, author, queue_id
- `hash_state`: id (always 1), last_hash, updated_at
- `queue_entries`: id, description, tags, created_at, status, completed_hash, completed_at

**Depends on:** none
